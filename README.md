# Simple Expense Tracker using Microsoft Excel

## Project Overview
The Simple Expense Tracker is an Excel-based project designed to record, manage, and analyze daily expenses. It helps users understand their spending habits through formulas, category-wise analysis, and visualizations.

## Project Objectives
- Track daily expenses.
- Calculate total monthly expenses.
- Analyze expenses by category.
- Analyze payment methods.
- Understand spending patterns.

## Tools Used
- Microsoft Excel
- Excel Formulas
- Data Analysis
- Data Visualization

## Excel Functions Used
- SUM()
- AVERAGE()
- COUNTA()
- SUMIF()
- TEXT()

## Project Features
1. Expense tracking with date, description, category, amount, and payment method.
2. Automatic month extraction.
3. Total expense calculation.
4. Average expense calculation.
5. Category-wise expense analysis.
6. Payment method analysis.
7. Monthly expense summary.
8. Pie chart visualization.

## Sample Expense Categories
- Food
- Transport
- Bills
- Shopping
- Entertainment
- Education

## Project Outcome
Created an interactive and formula-based expense tracking workbook that helps users monitor monthly spending and understand their financial habits.
